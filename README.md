Here lies a 50-day project from my Object Oriented Design class at DSU. 
This was a very informative project for me, as my first project in Godot (migrating from Unity) and my first solo project that I had full creative control over.
OOD architecture and understanding Godot were the focuses of this assignment, and after submission and holidays I returned to the project to finish some incomplete features and replace some placeholder art.
Perhaps one day I'll finish it. It's quite good in my opinion, given the short time spent working on things.
I learned Godot, json files, and CSS for this project in addition to its required scope.

Currently, there is an ESC menu to adjust sound, and the only implemented scene path is book 1, volume 1, chapter 1, scene 1.
The stories are adapted from TTRPG sessions ran by myself and my close friends, beginning with my own GM material, later adding the campaigns I was a player in.
It exists as a proof-of-concept to help me familiarise myself with the editor and design paradigm I chose, while adding more scenes and QoL over time.

It was a great learning experience and a fun way to put concepts into practice, which I would recommend to anyone trying to learn anything - find some way to make it fun for you, and experience real design challenges.
